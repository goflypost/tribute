# Present

**Question:** Can I accomplish the core thing? How many steps, how many dead ends?

## Mission

Identify the app's core promise (from its own landing copy) and attempt to
accomplish it once, end to end, as a first-time user. Count the steps. Record
every dead end: buttons that do nothing, links to nowhere, features that are
advertised but missing, states you can't get out of. If the core action is
gated behind payment, go as far as the gate and record what you could and
couldn't verify.

Max 30 actions.

## Scoring anchors

- **5** — The core promise is deliverable in an obvious, short path. Every
  control you touched did what it said. Nothing advertised was missing.
- **4** — Core thing works with minor detours: an extra step, one confusing
  label, a control you had to hunt for.
- **3** — You accomplished it, but the path fought you: unclear next steps,
  redundant confirmations, or one advertised feature that didn't work.
- **2** — The core promise is only partially deliverable: major advertised
  functionality is missing or broken, or you hit dead ends that forced a
  restart.
- **1** — The core thing cannot be done. The demo is a facade.
